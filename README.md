# ∑ LibreFormel v1.0.0

**LibreFormel** ist eine kostenlose, **100 % offline-fähige Erweiterung für LibreOffice Writer**, mit der sich mathematische und chemische Formeln schnell, sauber und ohne Umwege erstellen, rendern und umwandeln lassen.

---

## ✨ Funktionen im Überblick

* **Direktes LaTeX-Rendering in Writer:** Schreibe LaTeX-Code direkt im Dokument oder im Editor und füge gestochen scharfe Formeln ein – komplett lokal ohne Internetverbindung.
* **Visueller Formelbaukasten (Mathematik):** Klicke komplexe Brüche, Integrale, Summen, Matrizen, Wurzeln und griechische Symbole per Mausklick zusammen – inklusive Live-Vorschau (KaTeX) und Vorlagenbibliothek.
* **Formelbaukasten Chemie:** Reaktionsgleichungen, Aggregatzustände, Ladungen, Bindungen und ein **interaktives Periodensystem mit allen 118 Elementen** (inklusive Ordnungszahl und Atommasse).
* **Flexible Konvertierung & Export:** Wandle fertige Formeln oder ganze Dokumente bei Bedarf in **Word-kompatibles UnicodeMath**, **ASCIIMath** oder **Inline-LaTeX** um.
* **Eigene Formelsammlung:** Speichere häufig genutzte Formeln lokal ab und lade sie jederzeit mit einem Klick wieder.
* **100 % Offline & Datenschutzfreundlich:** Alle Bibliotheken (KaTeX, React, Tailwind CSS) sind lokal im Paket enthalten. Es werden keinerlei Daten an externe Server übertragen.

---

## 📥 Installation in LibreOffice Writer

1. Lade die aktuelle Datei **`LibreFormel_V1_0_0.oxt`** rechts unter **[Releases](../../releases)** herunter.
2. Öffne **LibreOffice Writer**.
3. Gehe im Menü auf **Extras → Extension-Manager…** (oder drücke `Strg + Alt + E`).
4. Klicke auf **Hinzufügen…**, wähle die heruntergeladene `LibreFormel_V1_0_0.oxt` aus und bestätige die Installation.
5. Starte LibreOffice einmal neu – danach steht dir **LibreFormel** direkt in der Symbolleiste / im Menü zur Verfügung.
